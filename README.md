# ⏳ Focus Timer

A modern and minimal **Pomodoro Focus Timer** built with HTML, CSS, and JavaScript to help students, developers, and professionals stay productive using structured focus sessions.

## 🌐 Live Demo

**https://mohamedwael-dev.github.io/Focus-Timer/**

---

## ✨ Features

* ⏱️ Custom Focus Timer
* ▶️ Start, Pause & Reset
* 🍅 Pomodoro Technique Support
* 🔔 Audio Notification
* 📱 Fully Responsive Design
* ⚡ Smooth Animations
* 💾 Local Storage Support
* 🎯 Simple & Clean UI

---

## 🛠️ Built With

* HTML5
* CSS3
* JavaScript
